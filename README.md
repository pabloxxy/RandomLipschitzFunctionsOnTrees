# RandomLipschitzFunctionsOnTrees
Based on a paper by Butler, Krishnan, Ray, and Spinka

This is mostly to study boundary distributions of the type 1/2 \delta_{-L} + 1/2 \delta{L}.

"animation.py" applies F until the support is an interval and then applies \psi.

"animationEpsilon.py" adds epsilon of mass in between the peaks, so inside the interval [-L, L] and also outside the interval. Then it applies psi to see the evolution of the distribution when n grows.
